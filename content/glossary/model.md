When people talk about an AI "model", they mean the thing that has been trained. Think of it as the result of all the learning: a large file of numbers that captures the patterns found in the [training data](/glossary/training-data). Give it something new and it applies those patterns to produce a response.

A single model can sit behind many products. The same [large language model](/glossary/large-language-model) might power a company's chatbot, a writing assistant and a customer service tool, each with its own design on top. Companies release new versions of their models over time, often with names and numbers.

The model is not the whole app. The website or program you use adds features such as saved chats, safety filters or web search. So two tools built on the same model can behave quite differently.
